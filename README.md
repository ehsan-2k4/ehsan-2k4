<details> <summary><b>🧠 Why Spec-Driven Development?</b> <sub>(click)</sub></summary> <br>
Most AI-assisted code fails not because the model is weak — but because the intent was never written down.

Vibe coding	Spec-driven
Prompt → hope → patch	Spec → plan → tasks → implement
Context dies with the chat	Context lives in the repo
Unreviewable diffs	Reviewable intent
Rewrite to change	Re-spec to change
My loop: constitution.md sets non-negotiables → spec.md defines what & why →
plan.md picks how → tasks.md breaks it into verifiable units → only then, code.
